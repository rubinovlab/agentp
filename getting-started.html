Getting started

What AGENT-P needs, how to install it, and how to download the expression models.

1.Requirements

AGENT-P runs on Linux and macOS. It is a Python package that calls a few genetics programs, all of which are installed together with conda in the next step:

SoftwareVersionUsed for
Python3.10AGENT-P itself, with numpy (< 2), pandas, SciPy (≥ 1.11), statsmodels, h5py, matplotlib, and bgen-reader
PLINK 22.00a5.12quality control of genotypes, and preparing genotypes for the models
bgenix1.1.7reading genotypes in BGEN format
REGENIE3.6GWAS (optional)
R4.2FUSION models (with optparse, RColorBrewer, and plink2R, which comes with AGENT-P)
  • Disk space: about 2 GB for the expression models.
  • Memory: a laptop with 8 GB is enough for the example. For large cohorts (tens of thousands of subjects), use a computing cluster.
  • Windows: use WSL (Windows Subsystem for Linux) and follow the Linux instructions.

2.Install

The easiest way to install AGENT-P and everything it needs is with conda (if you do not have conda, install Miniforge first). Open a terminal and run:

Terminal
git clone -b agentp-update-20261105 https://github.com/nhunghoang/agentp.git
cd agentp
conda env create -f environment.yml      # takes 5-15 minutes
conda activate agentp
pip install --no-deps -e .
R CMD INSTALL agentp/external/plink2R/plink2R

The commands on this page are run from this agentp folder.

On a Mac with an Apple chip (M1–M4), create the environment with the line below instead (the genetics programs are only available for Intel Macs, and run through Rosetta), and run conda config --env --set subdir osx-64 after conda activate agentp:

Terminal
CONDA_SUBDIR=osx-64 conda env create -f environment.yml

Each time you open a new terminal, run conda activate agentp before using AGENT-P.

Install with pip (PyPI)

AGENT-P is also on PyPI (Python 3.9 or later):

Terminal
pip install agentp

This installs AGENT-P and its Python packages only. PLINK 2, bgenix, REGENIE, and R (with plink2R, for FUSION) must be installed separately. Download the models as below, and tell AGENT-P where they are at the start of each script:

Python
from agentp import set_models_dir
set_models_dir('/path/to/models')

3.Download the models

The expression models (about 2 GB) are not included in the GitHub repository. Download models.tar.gz and extract it into the agentp folder inside the repository:

Terminal
cd agentp                                # the "agentp" folder inside the downloaded repository
tar -xzf ~/Downloads/models.tar.gz       # change the path if you saved the file elsewhere
cd ..

The models are now in agentp/models: models from four TWAS methods for eight brain regions (GTEx v8). In AGENT-P, each method and region has a short code, and any method can be combined with any region, e.g. SummaryTWAS(project, 'FUS', 'hippocampus'):

The example does not need this download: it uses a small set of example models that comes with AGENT-P.

4.Check the installation

Each of these commands should print a version or a message, without errors:

Terminal
python -c "import agentp; print('AGENT-P is ready')"
plink2 --version
bgenix -help | head -1
regenie --version
Rscript -e "suppressMessages(library(plink2R)); cat('plink2R is ready\n')"

Then you can either:

  1. run the example on your computer, which uses the small example models; or
  2. use the full models: test the pipeline with python tests/test_pipeline.py, which runs every step of AGENT-P (add --fusion to include FUSION), then analyze your own data with the Full run.

5.Troubleshooting

  • git clone fails with an error about "LFS" or "smudge filter". Clone without the large files (the models come from the download above anyway): GIT_LFS_SKIP_SMUDGE=1 git clone -b agentp-update-20261105 https://github.com/nhunghoang/agentp.git.
  • conda env create is very slow or runs out of memory. Use micromamba with the same file: micromamba create -f environment.yml.
  • numpy or h5py errors after installing. AGENT-P was installed without --no-deps, and pip replaced conda's packages. Remove the environment (conda env remove -n agentp) and install again.
  • On a Mac: "incompatible architecture". The environment was created without CONDA_SUBDIR=osx-64. Remove it and create it again as above. The first run on a Mac can take a few extra minutes while Rosetta translates the programs.
